# Kampánykörút

## Playwright test agents

The `playwright-test-planner`, `playwright-test-generator` and `playwright-test-healer` agents in
`.claude/agents/` are generated by `npx playwright init-agents --loop=claude`. Project-specific
rules for them live in `playwright/AGENT_RULES.md`, which regeneration does not overwrite.

- When delegating to these agents, tell them to read `playwright/AGENT_RULES.md` first.
- Regeneration overwrites the agent files, `.mcp.json` and `playwright/seed.spec.ts`; restore the
  project versions afterwards as described at the top of `playwright/AGENT_RULES.md`.
