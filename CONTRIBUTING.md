# Contributing to Kampánykörút

Thanks for your interest in contributing to **Kampánykörút**!

Community participation is very welcome. In fact, one of the main reasons I started this project was to create something that others can also contribute to, improve, and expand.

There are many ways you can help the project, including:

- implementing new features
- fixing bugs
- improving the UI/UX
- refactoring or improving existing code
- writing or improving campaign scenarios
- adding questions, answers, events, advisor feedback, or other campaign content
- improving documentation

## Before you start working

**Please open an issue before starting significant work**, and wait until the proposed change has been approved.

Alternatively, you can pick an existing issue that has already been approved and is open for contribution.

This is mainly to avoid situations where you spend a significant amount of time implementing something that doesn't fit the direction of the project.

Pull requests are always welcome, but **I cannot guarantee that unsolicited changes without prior discussion will be merged**.

For very small fixes — such as typos, minor documentation corrections, or similarly straightforward changes — opening an issue beforehand is usually not necessary.

## Contribution workflow

1. Check the existing issues to see if your idea or problem has already been discussed.
2. If not, open a new issue describing what you would like to change.
3. Wait for the issue to be approved before starting significant implementation work.
4. Fork the repository and create a branch for your changes.
5. Implement your changes.
6. Test your changes where applicable.
7. Open a pull request and reference the related issue.

Keeping pull requests focused on a single issue or feature makes them much easier to review.

## Campaign contributions

Contributions are not limited to programming.

New campaigns, campaign events, questions, answers, historical research, balancing improvements, and other content contributions are also very welcome.

If you would like to create or significantly expand a campaign, please open an issue first and describe the idea. This allows us to discuss the scope, historical context, game mechanics, and how it fits into Kampánykörút before a large amount of work is done.

Campaign content should aim to:

- represent the political and historical context accurately
- provide meaningful choices rather than obvious "correct" answers
- remain consistent with the tone and mechanics of the game
- distinguish historical facts from fictional or alternate-history scenarios where necessary

## Pull requests

When opening a pull request, please:

- link the related issue
- briefly explain what the change does
- mention any important implementation decisions
- include screenshots or recordings for significant UI changes when useful
- make sure the project builds and relevant tests pass

Feedback or requested changes during review are a normal part of the contribution process.

## Questions and ideas

If you're unsure whether an idea would fit the project, feel free to open an issue and discuss it before implementing anything.

Ideas, suggestions, bug reports, and contributions are all appreciated.

Thank you for helping make **Kampánykörút** better.
